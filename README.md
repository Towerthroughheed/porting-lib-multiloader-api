# Porting Lib — Fabric Porting Framework

[![Download Latest](https://img.shields.io/github/v/release/Towerthroughheed/porting-lib-multiloader-api?style=flat-square&label=Download&color=brightgreen)](https://github.com/Towerthroughheed/porting-lib-multiloader-api/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A library providing Forge-like APIs on Fabric, enabling faster ports of Forge mods to Fabric.

## Features

- Forge capability system ported to Fabric
- Fluid handling and tank APIs on Fabric
- Entity and block event hooks matching Forge patterns
- Used by Create Fabric, Immersive Engineering Fabric port
- Actively maintained for latest Fabric API versions

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
